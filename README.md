# Smart Industrial Energy Predictor ⚡

A machine learning web application built for minor projects and academic presentations. It predicts the energy consumption ($kWh$) of industrial machinery using three core algorithms: **Linear Regression**, **K-Nearest Neighbors (KNN)**, and **Decision Tree Regressor**, trained on telemetry data inspired by the UCI Steel Industry Energy dataset.

---

## 📁 Project Structure
- `app.py` — Streamlit application script containing the machine learning models, training pipeline, and interactive user interface.
- `requirements.txt` — List of required Python dependencies.
- `README.md` — Project documentation and setup instructions.

---

## 🛠️ Tech Stack
* **Frontend & Backend UI:** Streamlit
* **Machine Learning & Metrics:** Scikit-Learn (`LinearRegression`, `KNeighborsRegressor`, `DecisionTreeRegressor`, `R² Score`, `MAE`)
* **Data Processing:** Pandas, NumPy
